# Aptlantis-Logo website theme

Load apt-logo-website.css and place apt-site on the body or containing element. Components opt in with apt-* classes; apt-logo-website-landing.html and apt-logo-website-components.html document the DOM contract. The .apt-site namespace avoids styling an unrelated host page.

Scoped .apt-site CSS custom properties and opt-in .apt-* components; opaque dark surfaces. Preview interactions are illustrative. Existing framework integration, screen-reader review, CVD/category separation and production acceptance require separate review. Status labels remain necessary when source hues alias.

No framework adapter, installation, activation or publication is performed. Generated previews are illustrative and forms save no data.
